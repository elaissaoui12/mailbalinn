# Professional CV Generator

## Files Created

1. **Professional_CV.html** - Your professional CV in HTML format
2. **create_cv.py** - Python script for generating Word documents (requires python-docx)

## How to Use

### Option 1: Open HTML in Word (Recommended)
1. Open Microsoft Word
2. Go to File → Open
3. Select `Professional_CV.html`
4. Word will automatically convert it to a Word document
5. Save as `.docx` format (File → Save As → Word Document)

### Option 2: Open in Browser and Save as PDF
1. Open `Professional_CV.html` in any web browser
2. Press Ctrl+P (or Cmd+P on Mac) to print
3. Select "Save as PDF" as the printer
4. Save your CV as a PDF file

### Option 3: Use Online Converter
1. Go to any HTML to DOCX converter (e.g., CloudConvert, Zamzar)
2. Upload `Professional_CV.html`
3. Download the converted Word document

### Option 4: Install python-docx and run the script
If you have pip available:
```bash
pip install python-docx
python3 create_cv.py
```

## Customization

Edit the `Professional_CV.html` file to customize:
- Personal information (name, email, phone, location)
- Professional summary
- Work experience
- Education
- Skills
- Certifications
- Projects
- Languages

The CV is professionally formatted with:
- Clean, modern design
- Professional color scheme (blue and gray)
- Print-friendly layout
- ATS-friendly structure
- Proper spacing and typography

## Tips for Your CV

1. **Keep it concise**: 1-2 pages is ideal
2. **Use action verbs**: Led, Developed, Implemented, Achieved
3. **Quantify achievements**: Use numbers and percentages
4. **Tailor to the job**: Customize for each application
5. **Proofread**: Check for spelling and grammar errors
6. **Update regularly**: Keep your CV current

Good luck with your job search!
